# BEYOND GRAVITY 提示词分阶段执行协议 (PROMPT_PROTOCOL.md)

本协议依据《超越重力：天空的代价》独立整理版（2026-11-20）之第 F 节与 G 节制定，用于规范每一个 Phase 的生命周期与交付边界。

## 01. 阶段划分总览
- **Phase 0 · 免费能力与资料边界**：环境审计、权限解除、Git 初始化、docs 体系就绪、无网络依赖脚手架验证。
- **Phase 1 · 项目与视觉系统**：建立 React/TS/Vite 稳定工程骨架，定义全局色彩/间距/动效 Design Tokens、六幕导航与状态契约、404/回退处理、低动效与低性能开关。
- **Phase 2 · 全量静态安全内容**：建立 FHA、FMEA、FTA、STPA 静态学术数据体系，挂载完整证据链与事实标签，确保无动效时学术内容依然可独立阅读与追溯。
- **Phase 3 · 电影式片头**：ACT 0 侧逆光剪影、标题动画与进入/跳过交互，保证无残留遮罩与瞬时响应。
- **Phase 4 · 飞行器结构探索**：ACT II 六大子系统高精度 2D SVG 分层技术解剖图，按需交互式热点与侧边栏安全关联。
- **Phase 5 · 安全分析交互组件**：可筛选排序的 FMEA 交互表、可折叠交互式 FTA 树、STPA 控制回路与验证矩阵。
- **Phase 6 · 故障情境与风险传播**：ACT III 三大教学故障情境（EX-01, EX-02, EX-03）因果链状态点亮与实时面板。
- **Phase 7 · 统一时间线与状态管理**：全局状态流向收口，清除并发动画竞态与内存泄露，支持高频点击与快速跳章。
- **Phase 8 · 性能、安全与自动化审计**：执行长任务排查、响应式测试、无障碍可访问性审计与静态构建包安全扫描。
- **Phase 9 · 导出、部署、交付**：GitHub Pages 静态配置验证、公网可访问性复核、交付说明与清单。

## 02. 单阶段交付汇报模板规范（七步法）
每个阶段结束时，严格以中文输出：
1. **完成工作范围** (Completed scope)
2. **本阶段修改/创建的文件列表** (Modified files)
3. **增加的事实标签与来源** (Factual labels and sources added)
4. **实际执行的测试与精确结果** (Tests actually run and exact results)
5. **尚未解决的问题** (Unresolved issues)
6. **下一阶段前置条件** (Next phase prerequisites)
7. **回滚路径** (Rollback path)
