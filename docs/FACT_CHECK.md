# BEYOND GRAVITY 事实核验与标签追踪表 (FACT_CHECK.md)

本项目严格实行四级事实分类标准：
- **[F] Verified Public Fact**：经过监管官方通告或厂商公开文件直接证实的事实，必须注明来源出处与编号。
- **[A] Engineering Assumption**：具有严格学术边界的合理工程推导与分析假设，用于展开因果分析。
- **[D] Teaching Diagram / Demo**：教学示例模型或交互演示数据，不代表真实飞行器实时传感数值。
- **[U] Unverified Claim**：未经第三方证实或缺乏公开直接证据的宣传项，禁止作为结论写入。
